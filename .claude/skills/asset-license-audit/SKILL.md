# Asset and License Audit

Before adding an image, sprite, sound, track, font, or code snippet:
1. Open the original creator's asset page.
2. Verify the exact license and version for the exact asset pack / file.
3. Check whether attribution, share-alike, non-commercial, or other conditions apply.
4. Download / preserve the included license file where provided.
5. Record creator, source URL, asset file path, license, attribution text, modifications, and check date in `docs/ASSETS_AND_LICENSES.md` and the generated credits file.
6. Do not use unclear, scraped, unlicensed, or merely "free download" assets.
7. Do not include an asset just because it is available. It must serve the game's lunar mission art direction.
8. Do not add an entire large pack when only one sprite or sound is needed.
